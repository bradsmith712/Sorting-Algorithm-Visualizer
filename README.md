# Sorting Algorithm Visualizer

Watch common sorting algorithms work step by step.

**[Launch the visualizer →](https://bradsmith712.github.io/Sorting-Algorithm-Visualizer/)**

## Algorithms

* Bubble Sort
* Insertion Sort
* Selection Sort
* Quick Sort
* Heap Sort
* Merge Sort

## Features

* Adjustable array size and sort speed
* Data patterns: random, nearly sorted, reversed, few unique
* Color-coded bars for comparing, swapping and sorted elements
* Live comparison and swap counts, plus time and space complexity for each algorithm

## Running locally

    npm install
    npm start        # dev server at http://localhost:3000
    npm run deploy   # build and publish to GitHub Pages

## Tech Stack

* React (+ hooks)
* Redux
* TypeScript

Bootstrapped with [Create React App](https://github.com/facebook/create-react-app).
